# Development

## Prerequisites

Before you start coding you will first need to have a working installation of PyQt6 on your system, along with several Python Modules installed. 
This section will guide you through the installation that are needed prior to any code development phase.

---

### PyQt6

PyQt6 for Windows can be installed as for any other application or library. As of Qt 5.6 installers are available to install via PyPi, the Python Package archive. To install PyQt6 from Python3 simply run —

```
pip3 install pyqt6
```

Additionally, PySide6 must be installed as well. To install PySide6 from Python3 simply run —

```
pip3 install pyside6
```

### Python Modules

Apart from PyQt6 and PySide6, the application uses several modules for the algorith calculations along with the graph creation.
Specifically, the modules **pyqtgraph**, **pandas** and **scipy** are utilized.
To install the aforementioned modules, simply run —

```
pip3 install pyqtgraph
pip3 install pandas
pip3 install scipy
```
